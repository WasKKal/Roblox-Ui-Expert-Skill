# Roblox UI 常见坑清单（审计 / 排查用）

浓缩自 130+ 轮真实 UI 库（DynamicCowUI 风格）的审计与修复经验。每条含
**症状 / 根因 / 在本 Skill 里怎么查**。用 `Snapshot` 的三类视图对照即可快速定位。

---

## A. 布局与尺寸

1. **UIPadding 误以为会缩小 Size 的 Scale 基准**
   - 症状：加完 padding 控件反而偏移/变大。
   - 根因：`Size`/`Position` 的 `Scale` 相对**父级完整尺寸**；`UIPadding` 只收缩
     `UIListLayout` 的内容区，不改变 Scale 基准。
   - 查：结构树里看父级尺寸与子级 `Size` 的 Scale 值，手算 `scale*父尺寸+offset`。

2. **UIListLayout 顺序错乱**
   - 症状：控件上下/左右顺序与代码不一致，或偶尔颠倒。
   - 根因：顺序由 `LayoutOrder`（或 `Name` 排序）决定，不是 `Instance.new` 插入序；
     `table.sort` 不稳定会让同 `LayoutOrder` 的兄弟交错。
   - 查：结构树看 `LayoutOrder`；用 `(LayoutOrder, 原始插入序)` 稳定排序。

3. **ScrollingFrame 内容整体偏移 / 被裁切**
   - 症状：列表项跑到框外或看不到。
   - 根因：子级坐标要减 `CanvasPosition`；`Clipping`/`ClipsDescendants` 默认 true。
   - 查：结构树看 `CanvasPosition` 与子级绝对坐标差。

4. **CJK 文本溢出**
   - 症状：`!! 文本溢出` 告警，或文字被压扁/换行错乱。
   - 根因：全角字符按 1 em、ASCII 按字体系数（Gotham 0.60 等）度量；字号×字宽 > 框宽即溢出。
   - 查：结构树里 `!! 文本溢出: "X" 约 Npx > Mpx` 直接给出数值。

5. **UICorner 把整块擦成透明**
   - 症状：圆角框背景整体消失。
   - 根因：圆角擦除必须**限定在圆角盒内**（沿两轴距角点 ≤ radius），否则
     `dx²+dy² > r²` 会把矩形内部全判为「角外」清除。
   - 查：看色彩网格里框体是否整片空白。

## B. 层级与遮挡

6. **ZIndex 跨父级不生效**
   - 症状：子控件被兄弟层级的某元素盖住。
   - 根因：默认 `ZIndexBehavior = Sibling`，`ZIndex` 只在**同父级**内比较。跨层级要
     用 `DisplayOrder`（ScreenGui）或设 `Global`。
   - 查：结构树看每个节点的 `Z=` 与父级；后绘环/绘制顺序按 `(ZIndex, 原始序)`。

7. **蒙版/遮罩超出银白边框**
   - 症状：黑色遮罩四角露出在边框外。
   - 根因：蒙版没加 `UICorner` 或尺寸锚点没内缩。
   - 查：ASCII 线框看蒙版边是否贴合边框圆角。

8. **选中指示器盖住文字**
   - 症状：高亮条压在文本上导致看不清。
   - 根因：指示器 ZIndex 过高且没给文字留透明通道。
   - 查：色彩网格看指示器格是否覆盖了文字格。

9. **下拉菜单被蒙版/上级盖住**
   - 症状：展开的下拉条目点不到或看不见。
   - 根因：条目 ZIndex 低于蒙版，或父级 `ClipsDescendants` 裁剪。
   - 查：结构树确认下拉条目的 Z 与可见性。

10. **切换面板黑背景超出银白边框**
    - 症状：切换时黑色背板溢出边框圆角。
    - 根因：背景尺寸/锚点未内缩，且未随边框圆角化。
    - 查：ASCII 线框比对背景与边框轮廓。

## C. 描边 / 文本 / 图像

11. **UIStroke / 边框盖住文字**
    - 症状：文字像被 `#` 描边字符穿透（`D#e#m#o#...`）。
    - 根因：描边与文字落在同一网格行，内联绘制时描边覆盖了字形。
    - 查：ASCII 里若字母间夹 `#` 即此问题；本运行时已用「后绘环」避让——若仍出现
      说明后绘环未覆盖该装饰类，需登记 pendingRing。

12. **ImageLabel 不显示**
    - 症状：图标位置空白。
    - 根因：mock 里图像只做**占位**（`rbxasset://...` 不解码像素）；真实环境要
      确保图标资源已下载（Lucide 等）。
    - 查：结构树里看到 `ImageLabel ... [image=rbxasset://...]` 即正常占位。

13. **文本动画（渐绿→切换→恢复）残留绿色**
    - 症状：标题常驻绿色不恢复。
    - 根因：颜色补间没在切换完成后 `Color3` 复位，或补间被取消后状态未回滚。
    - 查：色彩网格看标题格颜色是否回到白色（#FFFFFF）。

## D. 动画 / 事件

14. **补间「属性没变」其实是已落定**
    - 症状：断言属性值发现 Play 后立刻就是终值。
    - 根因：本运行时 `Play()` **立即应用目标属性**，`Completed` 才延迟触发。变的是
      回调时机，不是属性值。
    - 查：用 `checkEqual` 看属性；用 `pump` 等副作用（显隐、UI 重建）。

15. **动画链卡住 / 不推进**
    - 症状：入场动画停在某一帧（如分裂球后不动）。
    - 根因：链的下一步挂在 `tween.Completed` 上，而库惯用「先 `Play()` 再
      `Completed:Connect()`」。若 Completed 是**同步**触发，Connect 永远错过。
    - 查：本运行时已让 `Completed` 延迟到补间时长后触发修复此问题。

16. **pump 一下等于「快进一帧」而非「推进 N 秒」**
    - 症状：`pump(4.0)` 后动画仍停。
    - 根因：若 pump 把整段时长作为一次让出，只跑一帧，`Heartbeat` 驱动的逻辑不前进。
    - 查：本运行时 `pump` 已改为按 1/60 逐帧让出；若仍有问题检查是否用了
      `M.pumpSeconds` 单跳。

17. **事件回调同步触发 vs 异步**
    - 症状：真实环境顺序不同。
    - 根因：mock 的 `Signal:Fire` **同步**调用已连接的 handler；真实 Roblox 是下一帧。
    - 查：依赖「连接后才 Fire」的逻辑要留意此差异。

18. **RenderStepped / Heartbeat 回调缺 dt**
    - 症状：依赖 `dt` 的旋转/进度算出来是 0 或 nil。
    - 根因：mock 的 `frameEvent` 会传 `dt`（虚拟帧长 1/60）。
    - 查：确认回调签名 `(dt, time)` 都接收。

## E. 状态机 / 多实例

19. **同 Title 脚本重复加载**
    - 症状：旧 UI 残留、控件叠加。
    - 根因：未做「已加载则跳过 / 先销毁旧实例」去重。
    - 查：`countInstances()` 看实例数是否异常增长。

20. **切换脚本时旧灵动岛文字叠加**
    - 症状：新界面出现，旧标题文字还在。
    - 根因：旧 `islandTextContainer` 未 Destroy。
    - 查：结构树看是否有多个同名 TextContainer。

21. **多脚本 UI 销毁动画缺失**
    - 症状：切到第二脚本时旧 UI 瞬间消失/残留错乱。
    - 根因：销毁路径没播动画、没 `unregisterLoadedWindow`。
    - 查：快照对比切换前后实例树。

22. **控件按调用顺序渲染错乱**
    - 症状：代码先加 A 后加 B，画面 B 在 A 上。
    - 根因：渲染顺序没埋点排序。
    - 查：结构树对照 `AddXxx` 调用顺序；可加 `_seq` 埋点后排序。

23. **Toggle 初始补间导致重建重播滑动**
    - 症状：每次重建 Toggle 都重播一次滑入动画。
    - 根因：初始 `Set` 触发了补间，重建时又触发。
    - 查：对初始值禁用补间（`Set(v, true)` 静默模式）。

24. **提示（ShowNotify）不自动结束 / 与展开冲突**
    - 症状：提示常驻或和面板展开打架。
    - 根因：没设 1.5s 自动结束，或入场下落/退场上移与展开动画未互斥。
    - 查：结构树 + pump 后看提示是否消失。

25. **三连点 hint 灵动岛上跳**
    - 症状：快速连点时灵动岛位置抖动上跳。
    - 根因：`hintActive` 过早置 false 导致偏移累加。
    - 查：连点场景下对比快照位置。

---

## 使用建议

- 改完布局/动画后，跑 `examples/demo_scenario.lua`（13 断言）与
  `examples/smoke_dynamiccow.lua`（19 断言）做回归。
- 排障时先看**结构树**（数值）、再对照 **ASCII**（轮廓）、最后看**色彩网格**（主题/
  渐变/遮挡）。三类视图互补，能替代截图。
